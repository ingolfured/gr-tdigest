# Installed Python runtime evidence

These are unchanged historical records from 21 October 2026 for
source `aaf7ab3956fed4269c1eaeef915a6faee78fa305` and the
`0.2.5.dev2026102102` / `0.2.5-dev2026102102` artifacts.
They do not qualify current `0.3.0` binaries.

The matrix has ten full installed-wheel cells and two Polars-free cells
covering Python 3.10–3.15 with the exact dependency versions recorded per
cell. Three source builds cover Python 3.12, 3.14 and 3.15. Together they
record 6,285 repeated passing executions, not independent statistical trials.

All entries refer to the old candidate in [artifact provenance](ARTIFACTS.md).
They do not establish support for every NumPy 2.x or Polars version, nor
validate current source archives or current installed-test counts.
